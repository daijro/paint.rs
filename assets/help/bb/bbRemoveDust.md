# Remove Dust

Remove Dust targets small specks in a scanned photograph. Choose the dust color so the effect can distinguish unwanted marks from the surrounding image.

It can handle many similar specks at once. A clone stamp gives more direct control over an individual repair, especially where a mark crosses important detail.

Run Remove Dust once on the image at full resolution. Repeated applications can wear away fine detail and reduce quality. Compare the preview closely before accepting, particularly around textured areas that resemble the dust color.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
