# Inner Shadow

Inner Shadow shades just inside an object's boundary. The result can make the object look like an opening cut into a surface.

For example, apply it to a solid letter on a transparent layer. The shadow sits inside the letter rather than falling outside it.

Change the shadow color to suggest different lighting or a colored surface behind the cut-out.

The Object menu uses the boundary between artwork and transparency, or the canvas edge. Keep the subject on its own layer so that boundary describes the object you want to shade.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
