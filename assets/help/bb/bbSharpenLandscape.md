# Sharpen Landscape

Sharpen Landscape combines common landscape-photo adjustments, making it useful for a batch of outdoor photographs.

Place the horizon marker where sky meets land.

Set the Sky and Grass amounts to suit the scene. Move Grass left when there is no grass to strengthen; adjust Sky similarly for the available sky.

The sharpening is intended for distant scenes photographed with focus at infinity.

Use the final multiply adjustment to bring out dynamic range, while checking that darker detail remains useful.

The process combines a sky gradient using Multiply, a grass gradient using Color Dodge, and a final multiplication of the image with itself.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
