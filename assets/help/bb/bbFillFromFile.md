# From File

From File fills the selection with an image from disk. Enter a path in File to load or use the file chooser. An image smaller than the fill area can repeat in tiles.

Use the placement control's + to position the image roughly, then refine its position with the numeric boxes.

Zoom changes the image scale. Normal resizing uses high-quality cubic resampling.

Choose Nearest neighbor sampling for clip-art or pixel art that needs crisp pixel boundaries.

Tiling methods control how copies meet. Mirroring alternate tiles can turn an image into a texture with less obvious seams.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
