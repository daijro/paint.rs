# Sharpen+

Sharpen+ is an unsharp mask that sharpens lightness only. Each pixel's red, green and blue are scaled together, so edges get crisper without colour fringes, and pure black never changes.

Set the three main controls first. Amount is the strength in percent, Radius is how far around an edge the sharpening reaches, and Threshold is the smallest contrast that gets sharpened, in tenths of a level, so fine noise can be left alone.

Then fine-tune with the tabs. Edge Balance sets the strength on the bright and the dark side of each edge separately, which helps tame halos. Shadows and Highlights lower the strength in the darkest and brightest tones; Tonal Range sets where each begins. The Color Mask sliders scale the whole effect by their average.

For questions about the original effect, visit the [Paint.NET forum](https://forums.getpaint.net/).
