# Combined Photo Effects

Combined Photo Effects puts several indoor-photo corrections in one dialog. It is useful when a batch of photos needs similar treatment.

Shadow Recovery supplies the shadow-lifting strength. The other controls draw on Brightness / Contrast, Temperature / Tint, and the saturation adjustment from Hue / Saturation. Adjust them while checking skin tones and areas that were originally dark.

The final multiply control changes the image's dynamic range. Try it after the other corrections, then compare the result with the original so important shadow detail remains visible.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
