# Transparency

Transparency changes the opacity of pixels inside the selection. Layer Properties changes the opacity of an entire layer instead.

Move the slider left to make the selected pixels more transparent, or right to make them more opaque.

The checkerboard shows where the image has become transparent. It is an editing aid rather than part of the picture.

Save as .PDN to retain your layered document, or .PNG to keep transparency in an exported image.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
