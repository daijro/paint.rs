# Paste Alpha

Paste Alpha uses an image on the clipboard as a mask for the current layer.

A mask can be shades of gray on an opaque background, or an image whose transparency describes the cut-out.

Prepare the mask on a layer, select it with Ctrl+A, and copy it with Ctrl+C before running Paste Alpha on the destination layer.

Choose the alpha source that matches your mask. Use Invert calculation if the wrong part disappears.

Once the mask has cut out the subject, try an outline or a drop shadow to separate it from its new background.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
