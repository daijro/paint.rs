# Dream

Dream softens detail and gives a photograph a hazy, dreamlike appearance. Try it on portraits or scenes where sharp texture distracts from the subject.

The effect blurs the image and combines that copy with the original using Darken. Radius controls the blur distance: increase it for a broader haze, then compare the preview with the original.

The original effect was also presented as a CodeLab effect-writing tutorial.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
