# Flames

Flames develops fire-like patterns from the image's brightness. The effect was inspired by Tom Jackson's fire tutorial on the [Paint.NET forum](https://forums.getpaint.net/).

First draw a black-to-white gradient, using white for the hottest part. Set Scale for the size of the pattern, then adjust Roughness for its texture.

For a monochrome result that you can color afterward, try Fog/Smoke. The current dialog uses this option rather than the older Black and White checkbox.

The starting gradient shapes the result. A narrow bright strip suggests a band of flame; a bright rounded area produces a different plume. Experiment with gradient shapes before changing the noise controls.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
