# Pastel

Pastel turns a picture into a painted image resembling watercolor or pastel chalk.

Set Pastel Size for the scale of the painted marks. Lower Roughness gives smoother watercolor-like areas; higher Roughness gives a more broken, chalky texture.

After the painting step, the recoloring normalizes hue and preserves saturation. It raises HSV value using V/3 + 0.8, limited to the available range, so even dark colors become lighter. It does not compress saturation or apply a separate near-black correction.

Pencil Size and Pencil Amount add a sketch over the painted result. Reduce Pencil Amount when you want the paint without those pencil marks.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
