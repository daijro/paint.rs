# Combined Adjustments

Combined Adjustments gathers several common changes in one dialog. Use Brightness / Contrast to set the overall tone, Temperature / Tint to balance a color cast, and Hue / Saturation / Lightness to change the colors. Sepia and black-and-white conversion provide alternate finishes, while Invert reverses the colors. Adjust the controls together and judge their combined preview before accepting the result.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
