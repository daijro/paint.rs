# Hue / Saturation+

Hue / Saturation+ chooses pixels by their existing color. This lets you target a color range within the current selection rather than adjusting every selected pixel equally.

Set the Pixel Selection sliders first, then use Pixel Adjustments to change the matching pixels.

Hue runs from From to To and can wrap past the end of the scale. To include reds on both ends, choose a range that crosses that boundary.

Gray pixels have no hue. Enable Also select gray pixels when they should be included.

Transparency Adjustment can make a chosen color range transparent.

Use Preview original image for an A/B comparison, and turn it off before OK to apply your adjustment.

To recolor a pink costume yellow, narrow the selection to its pink hues, then shift Hue Adjustment while checking neighboring colors.

The Hue Adjustment track illustrates the amount of rotation around the hue wheel. Its colors do not predict each pixel's final color.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
