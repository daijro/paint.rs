# Outline Object

The Object menu works on artwork bordered by transparency or the canvas edge. Text or a cut-out on its own layer is a typical object.

A selection is unnecessary, and these effects are easiest to judge with no selection limiting the result.

For example, start with a red letter on a transparent layer. Outline Object adds a rim, Bevel Object adds edge shading, and Inner Shadow shades inward.

Combine a bevel with a shadow when you want the letter to look raised above its background.

Feather Object has a different purpose: it softens the existing edge rather than adding an outline.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
