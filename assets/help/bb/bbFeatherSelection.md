# Feather Selection

Feather Selection softens the edge of the selected area by reducing opacity near its outline.

Select the object before opening the effect, then adjust the feathering while watching the edge.

A hard boundary becomes partly transparent after feathering, making the object merge more gradually with what lies underneath.

This can remove a background-colored fringe left by a magic-wand selection. Start with a small amount so you keep the subject's useful edge detail while softening the unwanted border.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
