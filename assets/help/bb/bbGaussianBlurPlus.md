# Gaussian Blur+

Gaussian Blur+ blurs selected channels while leaving the others untouched. This is useful when you want softer color detail without softening every component of the image.

Choose Radius first to set how far the blur spreads. Then enable the channels you want to blur and compare the preview. A small radius softens fine detail; a larger one blends broader areas. Leaving a channel unchecked keeps that channel's original values.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
