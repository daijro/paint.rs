# From Clipboard

From Clipboard inserts the clipboard image into your selection. If the image is smaller than the area to fill, it can repeat as tiles.

Drag the placement control's + for a rough position, then use its numeric boxes for precise alignment.

Zoom changes the size of the inserted image. Resizing normally uses high-quality cubic resampling to smooth the result.

Enable Nearest neighbor sampling for pixel art or clip-art when you want to keep hard pixel boundaries.

Choose a tiling method to control repetition. Mirrored tiles reverse alternate copies, which can help adjoining edges form a continuous texture.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
