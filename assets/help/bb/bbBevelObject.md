# Bevel Object

Bevel Object shades the edge of an object so it appears raised above the surface.

For example, text on a transparent layer can gain a rounded rim with a soft bevel, or a more sharply cut edge with a hard bevel. Compare both styles at the same size to see which suits the lettering.

The optional drop shadow adds separation between the object and the surface behind it.

The Object menu works from an object's boundary. An object is a group of pixels bordered by transparency or the canvas edge, such as a cut-out or a word on its own layer.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
