# Feather Object

Feather Object softens an object's edge by making its outer pixels more transparent.

An object is artwork surrounded by transparency or the canvas edge. A cut-out train on its own layer above a black background layer is one example.

No selection is needed. Run the effect on the layer containing the object and adjust the feathering while watching its outline.

Compare the solid edge before feathering with the translucent edge afterward. A small amount can remove a background-colored fringe left after deleting a background with the magic wand.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
