# Bevel Selection

Selection effects follow the selection boundary. Bevel Selection shades that boundary to give the selected area a raised edge.

A rectangular selection works, and clearing the selection uses the canvas edges. Curved outlines, hand-drawn selections and magic-wand selections usually show the effect more clearly.

The layer does not need transparency. Select the area whose outline should receive the effect.

For example, use the magic wand to select a red letter on an opaque background. The bevel follows the letter's selected shape rather than requiring it to be cut onto a transparent layer.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
