# Gradient

Gradient draws colorful transitions between two colors, including HSV rainbow effects.

Choose From Color / Alpha and To Color / Alpha first, then select the shape and interpolation algorithm.

The eight shapes are vertical, horizontal, both diagonal directions, radial from a corner, radial from a side, square, and conical. Compare a straight vertical transition with a conical sweep around the center.

Alpha Only keeps the image's colors and changes its transparency. It can fade an upper layer to show the layer beneath it.

RGB moves directly between channel values. HSV (short) follows the shorter path around the hue wheel; HSV (long) follows the longer path and passes through more hues.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
