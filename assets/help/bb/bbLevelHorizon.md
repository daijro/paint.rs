# Level Horizon / Plumb Bob

Level Horizon / Plumb Bob rotates a photograph until a line you mark becomes horizontal or vertical. Layers > Rotate / Zoom can do similar work, but this effect lets you mark the reference directly.

In Step 1: Mark Horizon, place the two + handles on the line. Drag them for coarse placement and use the controls for finer adjustment. Then switch to the finalizing tab to render the correction. The tabs replace the older Show guidelines checkbox.

Rotation can expose transparent corners. Zoom in slightly to crop them away, or retain the original background where available.

Use Plumb Bob for a vertical reference such as a wall. After a line is classified as vertical, the direction indicator stays vertical until the dialog closes, even if you move the handles back to a horizontal line. The rotation number still updates correctly.

For questions about the original effects, visit the [Paint.NET forum](https://forums.getpaint.net/).
